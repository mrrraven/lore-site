# Хрипка // Северный клан

Личный архив лора. Гости видят только чтение. Правка текста для публикации идёт через GitHub, не через открытый редактор на сайте.

## Как выложить

1. Создай репозиторий на GitHub и залей сюда содержимое папки `khripka_archive` (файлы должны лежать в корне репозитория, не во вложенной папке).
2. Settings → Pages → Branch: `main`, folder: `/root`.
3. Сайт откроется по адресу `https://<ник>.github.io/<репозиторий>/`.

Файл `.nojekyll` уже лежит рядом, чтобы GitHub не ломал имена в `assets`.

## Кто что может

- Обычный заход: дневник, сцены и карточки только для чтения. Кнопок «сохранить», «новая сцена» и режима редактора нет.
- Тебе, если нужно поправить прямо в браузере: открой любую страницу с `?edit=1` один раз. Флаг останется в этом браузере.
- Выключить локальную правку: `?edit=0`.
- То, что должны видеть все, лучше коммитить в репозиторий. Браузерное сохранение живёт только в localStorage этого компьютера и на GitHub Pages само не попадёт.
