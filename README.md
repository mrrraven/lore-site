# Хрипка // Северный клан

Личный архив лора. Гости видят только чтение. Правка текста для публикации идёт через GitHub, не через открытый редактор на сайте.

## Как выложить

1. Создай репозиторий на GitHub и залей сюда содержимое папки `khripka_archive` (файлы должны лежать в корне репозитория, не во вложенной папке).
2. Settings → Pages → Branch: `main`, folder: `/root`.
3. Сайт откроется по адресу `https://<ник>.github.io/<репозиторий>/`.

Файл `.nojekyll` уже лежит рядом, чтобы GitHub не ломал имена в `assets`.

## Кто что может

- Обычный заход: вся страница только для чтения. Кнопок «сохранить», «редактировать», «новая сцена» и режима редактора нет и быть не может — пин никто не вводил.
- Чтобы править: кнопка «войти» в правом нижнем углу, код по умолчанию `север` (меняется в `assets/studio.js`, переменная `PIN`). Это только впускает в браузер — сама правка **не включается автоматически**.
- После входа появляется вторая кнопка — «редактировать». Она включает режим правки на этой вкладке; «закончить правку» выключает его обратно в чтение. При обновлении страницы режим правки снова выключен (чтобы случайно не редактировать текст, когда просто зашёл посмотреть) — пин запоминается в браузере, а сама правка каждый раз включается заново кнопкой.
- `?edit=1` в адресе просто открывает форму входа (код всё равно нужно ввести). `?edit=0` выходит из архива в этом браузере.
- То, что должны видеть все, нужно нажать «опубликовать» — это коммитит `data/site.json` в репозиторий через GitHub API (нужен токен с правом Contents: Read and write). Черновик без публикации виден только в твоём браузере и на GitHub Pages не попадёт.
